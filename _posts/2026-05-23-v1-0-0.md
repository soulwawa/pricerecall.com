「얼마였지?」 v1.0 이 App Store 에 출시되었습니다.

## 새로운 기능

- **상품 가격 기록** — 반복 구매하는 상품의 가격을 매 구매마다 기록합니다.
- **실결제 단가 계산** — 영수증 금액에서 적립 포인트와 결제일 카드 할인을 빼고, 실제 부담한 금액 기준의 단가를 자동으로 계산합니다.
- **가격 추이 보기** — 상품별 구매 이력을 모아 단가가 어떻게 움직였는지 한 화면에서 확인합니다.
- **구매처 비교** — 같은 상품을 어디서 얼마에 샀는지 한눈에 보고 다음 구매를 결정합니다.
- **둘러보기 모드** — 회원 가입 없이도 데모 데이터로 앱을 체험할 수 있습니다.
- **이메일 OTP 로그인** — 비밀번호 없이 이메일 인증 코드만으로 로그인합니다. 데이터는 본인만 접근할 수 있도록 Row Level Security 가 적용됩니다.

## 시스템 요구사항

- iOS 17 이상
- iPhone 전용
